# Portfolio OS

A macOS-inspired portfolio website built with vanilla HTML, CSS, and JavaScript — 
draggable windows, a dock, and custom "apps" that showcase my work.

Inspired by [displace.agency](https://displace.agency).

## 🚧 Status
Work in progress — currently building the core window/drag mechanic before adding apps.

## Planned Apps
- 🔍 Finder — Projects
- 🧭 Safari — Links / resume
- 🛍️ App Store — Current & upcoming projects
- 📝 Notes — Notes / blog-style thoughts
- 💻 Terminal — Fun terminal-style interactions
- 🎵 Spotify — Favorite artists & songs
- 🎬 Netflix — Movie/drama recs

## Tech Stack
- HTML5
- CSS3 (no frameworks)
- Vanilla JavaScript (no frameworks/libraries)

## Running Locally
\`\`\`bash
git clone https://github.com/adi-tya-sha-a/portfolio-os.git
cd portfolio-os
# just open index.html in your browser, or use Live Server
